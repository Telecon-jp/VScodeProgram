内存四区
程序运行前：全局(global)区  代码区 
程序运行后：栈区  堆区

代码区
程序运行时，存放可执行机器指令的内存区域。
代码区是程序运行时，操作系统把可执行文件中的 .text 段加载到内存后形成的区域。编译链接后，机器指令在硬盘上的可执行文件里，还不叫代码区。

全局区:
全局变量（定义在函数之外的变量）  
静态变量（static int s_a=10;）
除了局部常量的常量：
      字符串常量（双引号引起来的）
      const修饰的全局变量，即全局常量，如const int a=10;
      *const修饰的局部（local）变量，即局部常量，在栈区，跟局部变量在一起

栈区：
函数的参数值（形参），局部变量常量
***注意：不要返回局部变量的地址！！

堆区：
由程序员分配释放，若不人为释放，最后由操作系统回收。在c++中主要利用new语句在堆区中开辟内存
//利用new关键字 
int *p = new int(10);
在堆区开辟了内存用来存10，用*p指针接受其地址
这个内存会一直存活直到释放
释放运用操作符delete
1.new的语法
数据类型 *指针名 = new 数据类型（数据）；
new返回的是其开启的内存的指针，用指针来接收
利用new开辟数组
int *arr=new int[10];
返回这个数组连续空间的首地址
2.释放堆区数据用delete
delete 指针名；
指针指向的内存释放之后指针就变成了野指针，不能访问
释放数组的时候要加一个空的中括号
delete [] arr;
