==================================================
  class 5 笔记总结 —— 函数 / 分文件编写
==================================================

一、函数的作用
  - 将一段经常使用的代码封装起来，减少代码量
  - 每个模块实现特定的功能

二、函数定义的五个步骤
  1. 返回值类型
  2. 函数名
  3. 参数列表
  4. 函数体
  5. return 表达式

  语法：
      返回值类型 函数名 (参数1, 参数2, ..., 参数n)
      {
          函数体语句
          return 表达式
      }
  - 注意：函数的定义不能写在 main 函数内

三、函数的调用
  - 语法：函数名(参数)
  - 示例：
        int add(int num1, int num2)
        {
            int sum = num1 + num2;
            return sum;
        }
        int main()
        {
            cout << add(a, b) << endl;
        }
  - 其中 a 与 b 为实参，num1 和 num2 是形式参数（形参）
  - 调用函数时，实参的值传递给形参

四、void 函数
  - 如果函数不需要返回值，声明时写 void
  - 示例（值传递不改变实参）：
        void swi(int num1, int num2)
        {
            int temp = num1;
            num1 = num2;
            num2 = temp;
            return;
        }
  - 输出结果中形参发生交换，但实参未发生交换

五、函数的常见形式
  1. 无参无返：void test1() { cout << "test1" << endl; return; }
  2. 有参无返
  3. 无参有返
  4. 有参有返

六、函数的声明
  - 当自定义函数写在 main 函数后面时，可提前声明，以便在 main 中调用
  - 示例：
        int max(num1, num2);   // 函数声明
        main() { ... }
        int max(num1, num2) { ... }   // 函数定义

七、函数的分文件编写
  1. 创建后缀名为 .h 的头文件
  2. 创建后缀名为 .cpp 的源文件
  3. 在头文件中写函数的声明
  4. 在源文件中写函数的定义
  - 在主文件中用 #include "head1.h" 引入

八、本课示例程序
  - 在 head1.h 中声明 max1 函数
  - main 中调用 max1(a, b) 输出较大值
