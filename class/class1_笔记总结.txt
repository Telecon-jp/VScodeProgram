==================================================
  class 1 笔记总结 —— C++ 入门 / 数据类型 / 运算符
==================================================

一、程序基本结构
  - #include <iostream>：预处理命令，将系统头文件包含进程序
  - using namespace std;：用 "std" 表示预加载的功能/函数
  - main 是程序入口，每个程序有且仅有一个 main 函数
  - return 0; 表示程序正常运行结束

二、变量与标识符
  - 创建变量语法：数据类型 变量名称 = 变量初始值
  - 标识符规则：只能用字母、数字、下划线；第一个字符不能是数字；
    不能使用关键字；字母区分大小写

三、整型
  1. 短整型：short
  2. 整型：int
  3. 长整型：long
  4. 长长整型：long long
  - 不同整型取值范围不同

四、sizeof 关键字
  - 利用 sizeof 求出数据占用的内存大小
  - 语法：sizeof(变量名称)

五、实型（浮点数）
  - 单精度 float；双精度 double（更精确）
  - 默认情况下，输出一个小数显示六位有效数字
  - 保留小数点后 n 位示例：
      #include <iomanip>
      cout << fixed << setprecision(5) << a;

六、字符型
  - 语法：char ch = 'a';
  - 注意：字符型变量赋值内容要用单引号引起来，且单引号内仅能有一个字母
  - 每个字母在 ASCII 表中都对应一个数字，可用 int(字符变量) 查看

七、转义字符
  - \a 警报；\n 换行符；打出两个 \\ 输出一个反斜杠

八、字符串类型
  - string sen = "hello world";

九、布尔类型
  - true（真） / false（假）；在 C++ 中除了 0 都是 true
  - bool flag = true;

十、数据输入
  - cin >> 想要赋值的变量

十一、运算符
  1. 算术运算符：% 取模（相除取余数），如 10 % 3 = 1
  2. 递增运算符：
     - 前置递增 ++a：先让变量加一，再进行表达式运算
       例：a=10, b=2, sum1 = ++a * b = 11 * 2 = 22
     - 后置递增 a++：先进行表达式运算，再让变量加一
       例：a=10, b=2, sum2 = a++ * b = 10 * 2 = 20
  3. 赋值运算符：a += 5 等价于 a = a + 5
  4. 比较运算符：== != < > <= >=，结果为 1(true) 或 0(false)
  5. 逻辑运算符：
     - ! 非：真假互换，如 !a
     - && 与：a && b，两者都真才为真
     - || 或：a || b，只要有一者为真即为真
