==================================================
  class 3 笔记总结 —— 循环结构
==================================================

一、while 循环语句
  while (循环的条件)
  {
      循环执行的语句
  }
  - 只要条件为真就一直执行循环体

二、随机数
  - rand() % 100：生成一个 0~99 的随机数
  - 通用公式：生成 [a, b] 闭区间随机数
        int x = rand() % (b - a + 1) + a;

三、数位提取（任意整数 a）
  - 获取个位：a % 10
  - 获取十位：a / 10 % 10
  - 获取百位：a / 100

四、for 循环
  - 作用：满足循环条件，执行循环语句
  - 语法：
        for (起始表达式; 条件表达式; 末尾循环体)
        {
            循环语句
        }

五、嵌套循环结构
  - 多层循环嵌套，常用于二维结构打印等

六、continue 语句
  - 作用：在循环语句中，跳过本次循环中尚未被执行的语句，
    直接进行下一次循环
  - 示例：
        for (.....) {
            循环语句1
            if (不想要继续执行循环语句2的情况) {
                continue;
            }
            循环语句2
        }
  - 注意区别 continue 和 break：
        continue 只跳过一次或多次循环，并不结束循环
        break 直接结束当前循环

七、goto 语句
  - 直接跳转到标记的语句执行
  - 示例：
        语句1
        语句2  goto FLAG
        语句3
        FLAG:
        语句4
        语句5

八、本课示例程序（"逢 7 过"游戏）
  - 遍历 0~100，取个位 b、十位 c、对 7 取余 d
  - 若 b==7 或 c==7 或 d==0，输出 "qiao"（敲桌子）
  - 否则输出数字 i
