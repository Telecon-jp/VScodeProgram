二、选择结构 —— if 语句
  1. 单行 if 语句：
       if (需要满足的条件) { 满足条件时执行的语句 }

  2. 多行 if 语句（if...else）：
       if (条件) {
           语句
       } else {
           语句
       }

  3. 多条件 if 语句（if...else if...else）：
       if (条件一)        { 语句一 }
       else if (条件二)   { 语句二 }
       ..........
       else if (条件n)    { 语句n }
       else               { 都不满足时的语句 }

三、三目运算符
  - 语法：c = (a > b ? a : b)
  - 含义：如果 a 大于 b 则输出 a，反之则输出 b，并将输出的值赋值给 c
  - 三目运算符返回的是变量，可以继续赋值
    例：(a > b ? a : b) = 100;  将较大的变量赋值为 100

四、选择结构 —— switch 语句
  switch (表达式)
  {
      case 结果一：执行语句; break;
      case 结果二：执行语句; break;
      .........
      default：执行语句; break;
  }
  - 前面几个结果都没出现的话，执行 default 里的语句
  - 注意每个 case 后要用 break 跳出，否则会继续向下执行

五、本课示例程序要点
  - cin >> a; 读取输入
  - char b = char(a); 将整型 a 强转为字符
  - if (0 < a && a < 255) 判断 a 是否在 ASCII 有效范围内
  - 在范围内输出对应字符，否则提示 "a is out of range"
