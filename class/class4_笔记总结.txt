==================================================
  class 4 笔记总结 —— 一维数组 / 二维数组
==================================================

一、一维数组的定义方式
  - 语法：数据类型 数组名[数组长度] = {n0, n1, n2, ...}
  - 注意：C++ 的数组从下标 0 开始
  - int arr[10] = {1,2,3};        // 剩余元素自动补 0
  - int arr[10] = {};             // 所有元素都是 0
  - int arr[] = {1,2,3,4,5};      // 省略数组长度，编译器自动判断

二、数组访问与遍历
  - 通过下标访问元素，如 arr[3] 是数组中的第 4 个元素
  - 常用 for 循环遍历数组

三、一维数组名称的用途
  - 元素个数 = sizeof(arr) / sizeof(arr[0])
  - cout << arr;          // 查看数组的首地址
  - cout << &arr[i];      // 查看第 i 个元素的地址，& 是取址符

四、数组元素逆置
  - 例：1,2,3,4,5 -> 5,4,3,2,1
  - 思路：引入临时存储变量 temp，首尾对称位置交换
  - 步骤：
      1. 起始下标 i = 0，末尾下标 e = 长度-1
      2. 当 i <= e/2 时循环：
           temp = arr[i];
           arr[i] = arr[e];
           arr[e] = temp;
           i++; e--;

五、二维数组的定义方式
  - 注意：行数和列数都从 0 开始
  1. 数据类型 数组名[行数][列数];
  2.（推荐）数据类型 数组名[行数][列数] =
        { {数据1, 数据2}, {数据3, 数据4}, {数据5, 数据6} };
     例：int arr[2][3] = {{1,2,3},{4,5,6}};
        其格式为：
          1  2  3
          4  5  6
     - 行数可以不写，电脑会自行判断行数
  3. 数据类型 数组名[行数][列数] = {数据1, 数据2, 数据3, 数据4};

六、二维数组的数组名
  - 同样可查看首地址、各行首地址等

七、多维数组的打印
  - 用多层的嵌套循环，每层循环打印一个维度
  - 例：外层循环控制行，内层循环控制列
